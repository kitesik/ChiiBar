# 집 성장 그림

2026-10-16 기준, 신분상승 토큰 치이카와의 13단계 집 배경이다. 내장 image_gen.imagegen 도구로 생성했다. 생성 지시는 prompts.json에 기록했다.

사용자 사진은 집 내부를 보여 주는 구조의 참고이며, 사실적인 재질과 디테일은 채택하지 않는다. 갈색의 둥근 선과 파스텔 색의 2D 그림체를 유지한다. 초반에는 빈약한 잠자리, 중반에는 완비된 생활 공간과 정원, 후반에는 넓은 방·복층·도시 전망·고급 편의시설로 공간과 소품 밀도를 크게 높인다.

- stage-01.png부터 stage-13.png까지 실제 앱에 포함한다.
- 배경에 인물을 그리지 않으며 캐릭터는 별도로 그려 움직인다.
- 바닥 중앙의 안전한 보행 구간을 사용한다. 가구·계단·수영장은 장식이며 현재 캐릭터는 계단을 오르거나 물에 들어가지 않는다.
- 초반 집은 작게 표시하여 집이 넓어지는 차이를 보여 준다.
- 생성 원본은 보존하며 앱에서는 비율을 유지하여 축소한다.

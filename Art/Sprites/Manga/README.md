# 원작 컷 기반 표정 목록

2026-10-16 기준, 앱에서 허용하는 9명·12종의 표정과 작가 원문 근거를 기록한다. 원작에서 확인하지 못한 표정은 추가하지 않는다.

## 적용 규칙

- 작가 `@ngnchiikawa` 공개 만화의 실제 컷을 직접 보고 눈·입·눈썹을 지정했다. 아래 이미지는 원본 페이지를 내장한 것이 아니라 built-in imagegen으로 다시 그린 게임용 이미지다. 픽셀 단위 원본 동일성을 뜻하지 않는다.
- 이전 공통 happy/sleep/blink 이미지와 미확인 하품 시안은 앱 패키지에서 제외했다. 클릭·감은 눈·입 벌림 등의 공통 명령으로 다른 표정이 자동 생성되지 않는다.
- 치이카와만 초반 1~2단계에서 24초마다 4초 동안 눈물 표정을 표시한다. 쓰다듬으면 안도 표정으로 전환한다. 이 발생 시점은 게임 연출이며 원작의 주거 설정이라는 뜻은 아니다.
- 하치와레는 쓰다듬을 때 원작의 다독이는 표정을 사용한다. 나머지는 아래 기준 표정을 유지하며 몸 이동·기울기·작은 점프로 반응한다. 아직 확인되지 않은 수면·하품 표정은 사용하지 않는다.
- `catalog.json`에 각 그림의 원문 링크, 구체적인 컷 위치, 생성 프롬프트와 수정 프롬프트를 보관한다. 공식 만화 페이지 자체는 앱에 포함하지 않는다.

## 수정 검수

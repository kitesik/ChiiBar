# ChiiBar contributor instructions

- Unofficial noncommercial fan app. Character rights belong to their owners.
- Do not copy, trace or embed official artwork. Use the original sprite seam.
- macOS 14+, Swift 6, SwiftPM. Rules in ChiiCore, UI in ChiiBar.
- Keep the game minimal: friends, house upgrades and home activities.
- Run `bash Scripts/check.sh` before commits. Keep SwiftUI views small.
- Never commit personal logs, saved state, credentials or private usage reports.
- Public releases require the maintainer's explicit authorization.

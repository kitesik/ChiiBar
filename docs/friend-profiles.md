# 친구 도감 기준

2026-10-16 기준, 앱 안의 15명 소개와 신규 6명 외형 식별에 사용한 자료입니다. 공식 그림 파일은 앱에 포함하지 않고 새 팬 스프라이트를 제작했습니다.

- [애니메이션 공식 캐릭터 소개](https://www.anime-chiikawa.jp/chara.html): 기존 8명, 파자마파티즈 그룹, 포셰트·노동 갑옷 씨의 역할과 관계. 한국어로 짧게 요약했습니다.
- [파자마파티즈 공식 발표](https://www.anime-chiikawa.jp/info.html?k=entry%2F240223): 초록·분홍·하양·보라 멤버 구분.
- [공식 홈페이지](https://www.anime-chiikawa.jp/): 아노코 표기. 별도의 공식 성격 설명이 없어 성격을 단정하지 않습니다.

파자마파티즈는 공식 그룹 소개를 공통 적용하며, 색별 성격을 임의로 만들지 않습니다. 게임 속 대사와 날씨 반응은 창작 연출이며 공식 설명과 구분합니다.

확률은 게임 설계값입니다. 치이카와 2%, 우사기 3%, 하치와레 5%, 모몽가 6%, 쿠리만쥬·시사·포셰트 갑옷·노동 갑옷 각 7%, 나머지 7명 각 8%로 총 100%입니다. 기존 보유 친구·집·뽑기권은 유지합니다.
